CollectEasy – Chit Fund Management & Collection System

Offline-First Field Mobile App · Centralized Admin Dashboard · RESTful Backend Engine

Key Project Highlight

"Developed an offline-first financial collection workflow that allows field agents to record payments without an active internet connection and synchronize pending transactions when connectivity is restored."

Project Overview

Designed and developed CollectEasy, a comprehensive chit fund management platform that digitizes financial operations, customer management, payment collections and administrative reporting.

The platform consists of three integrated modules: a centralized Admin Dashboard, an Offline-First Mobile Web Application for field agents, and a RESTful Backend API.

Key Features & Modular Breakdown

1. Centralized Admin Dashboard

  • Real-time collection and financial performance monitoring.
  • Chit group and subgroup management.
  • Customer directory and payment history.
  • Defaulter tracking and overdue payment monitoring.
  • Audit logs and synchronization monitoring.
  • Customizable business and receipt settings.

2. Offline-First Field App

  • IndexedDB-powered offline data storage.
  • Customer search by name, phone number and account code.
  • Cash and UPI collection processing.
  • Digital receipt generation.
  • Automatic background synchronization.
  • Reliable payment recording in low-connectivity environments.

3. Secure Backend & Financial Engine

  • RESTful API architecture using Node.js and Express.
  • MySQL database integration using connection pooling.
  • JWT-based authentication and role-based access.
  • Bcrypt PIN hashing & Zod-based request validation.
  • UUID-based idempotent payment processing.
  • Integer-based financial calculations using paise to avoid floating-point rounding errors.
